# MyLLMService — список покупок по блюду

Минимальное Gradio-приложение: пользователь указывает блюдо, количество человек и формат ответа, а приложение запрашивает у GigaChat список продуктов.

## Установка и запуск

Требуется Python 3.10+.

```powershell
cd MyLLMService
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `AUTHORIZATION_KEY` в `.env`, затем запустите:

```powershell
python gradio_app.py
```

После запуска откройте адрес Gradio, указанный в консоли.

## Интерфейс

UI содержит:

- многострочное поле «Что приготовить»;
- выпадающий список количества человек: `1`, `2`, `4`, `6`;
- выпадающий список формата: «Список продуктов» или «Список + шаги»;
- кнопку «Сгенерировать список покупок»;
- поле результата.

Вызов модели вынесен в `app/services/shopping_list_service.py`. UI только передаёт значения обработчику и показывает возвращённую строку.

## Проверки и ошибки

Ввод проверяется до обращения к API:

- пустой ввод: `Напишите, что хотите приготовить.`;
- более 1000 символов: `Слишком длинный текст — сократите или разбейте на части.`;
- неверные значения количества или формата: `Выберите количество человек и формат ответа.`

Ошибки API не показывают traceback и не раскрывают детали провайдера:

- ошибка доступа/настройки: `Не настроен доступ к сервису.`;
- HTTP 5xx: `Сервис временно недоступен. Попробуйте позже.`;
- timeout или сеть: `Не удалось получить ответ. Попробуйте ещё раз.`;
- пустой ответ: `Пустой ответ модели. Попробуйте переформулировать вопрос.`

## Ручные тест-сценарии

1. Нормальный ввод: введите `паста карбонара`, выберите `4` и `Список + шаги`, нажмите кнопку. Ожидается список продуктов по одному на строку и 5–8 коротких шагов.
2. Пустой ввод: оставьте поле блюда пустым и нажмите кнопку. Ожидается сообщение `Напишите, что хотите приготовить.`; запрос к API не выполняется.
3. Длинный ввод: вставьте строку длиннее 1000 символов. Ожидается сообщение `Слишком длинный текст — сократите или разбейте на части.`; запрос к API не выполняется.

Автоматические проверки запускаются командой:

```powershell
python -m unittest discover -s tests -v
```

Чтобы воспроизвести ошибку доступа, скопируйте `.env.example` в `.env` и оставьте `AUTHORIZATION_KEY=replace-with-provider-key`. Интерфейс покажет только `Не настроен доступ к сервису.` без traceback и секретов.

## Конфигурация

Настройки находятся в `.env` и не должны записываться в исходный код. Поддерживаются URL OAuth/API, ключ доступа, модель, timeout, количество попыток, задержка retry, TTL кеша и путь к JSON-логам.

Результаты идентичных запросов кешируются в памяти на 10 минут. Логи пишутся в консоль и `logs/service.log`.
