# MyLLMService

Минимальный FastAPI-сервис генерации анекдота через GigaChat.

## Установка и запуск

```powershell
cd MyLLMService
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# заполните AUTHORIZATION_KEY в .env
python -m uvicorn app.main:app --reload
```

Сервис доступен по адресу `http://127.0.0.1:8000`.

## Pipeline

1. FastAPI принимает и валидирует список тем (`1–5` непустых тем, длина темы до 100 символов).
2. `AppState` нормализует темы, после чего `JokeService` строит системный и пользовательский prompt и вычисляет ключ кеша.
3. `LLMClient` вызывает GigaChat с таймаутом и максимум тремя попытками с экспоненциальной задержкой для timeout/connection/5xx ошибок.
4. Ответ очищается и проверяется на формат `<Название>|<Текст>`.
5. Результат кешируется в памяти на 10 минут. При недоступности модели возвращается HTTP 503 с сообщением `Сервис временно недоступен, попробуйте позже`.

## Пример запроса и ответа

```bash
curl "http://127.0.0.1:8000/jokes/get_joke/?tags=python&tags=программирование"
```

```json
{
  "tags": ["python", "программирование"],
  "title": "Неожиданный баг",
  "text": "Текст сгенерированного анекдота",
  "created_at": "2024-01-01T12:00:00+00:00"
}
```

Ошибочный запрос получает HTTP 422 и JSON с полями `detail` и `errors`. При повторном идентичном запросе в логах появляется событие `cache_hit`.

## Конфигурация и логи

Настройки находятся в `.env`; шаблон — в `.env.example`. JSON-логи пишутся в `logs/service.log` и в консоль. В них фиксируются входящий запрос, prompt, ответ модели, ошибки, длительность запроса, длительность этапов pipeline и события `cache_hit`/`cache_miss`.
