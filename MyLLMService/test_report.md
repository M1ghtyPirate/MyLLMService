# Отчёт ручной проверки

Дата: 2026-10-30

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Валидный запрос с `tags=python` | HTTP 200, поля `tags`, `title`, `text`, `created_at` | Пройдено с замоканным LLM |
| Нет параметра `tags` | HTTP 422, понятное описание ошибки | Пройдено: HTTP 422 |
| Тема длиннее 100 символов | HTTP 422 | Пройдено: HTTP 422 |
| Недоступен LLM/сеть отключена | До 3 попыток, затем HTTP 503 с fallback-сообщением | Fallback пройден через имитацию ошибки; реальное отключение сети не выполнялось |
| Повторный идентичный запрос | HTTP 200, событие `cache_hit` в JSON-логе | Пройдено: один вызов LLM, затем cache hit |
| Просмотр `logs/service.log` | JSON-события request, prompt, response, error и duration | Пройдено: есть общая и поэтапная длительность |
| Автоматические тесты | Проверка pipeline без внешней сети | Пройдено: `python -m unittest discover -s tests` |

Пример команды для проверки:

```bash
curl "http://127.0.0.1:8000/jokes/get_joke/?tags=python"
```
