# ChangeLog

## 2026-11-02

- Добавлен выбор формата ответа: рекомендации по тексту или полный текст с исправлениями.
- Добавлены отдельные prompt-инструкции и кеширование для каждого формата.
- В выпадающем списке стилей отображаются названия с прописной буквы, а внутренние значения сохранены в нижнем регистре.

## 2026-11-01

- Сервис переведён на проверку стилистики текста.
- Добавлен выбор стиля: научный, официально-деловой и разговорный.
- Обновлены Gradio-интерфейс, бизнес-логика, prompt для LLM, кеширование, сообщения и документация.
- Добавлены обработка ошибок, fallback-ответ, retry, TTL-кеш и JSON-логирование.
- Настроены автоматические тесты и GitHub Actions CI-пайплайн.
