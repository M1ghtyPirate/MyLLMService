# Тестирование MyLLMService

## Цель проверки

Проверяется Gradio-сервис проверки текста на соответствие выбранному стилю:

- научный;
- официально-деловой;
- разговорный.

Сервис принимает текст, выбранный стиль и формат ответа, формирует prompt для GigaChat и возвращает рекомендации либо исправленный текст. Тесты используют mock LLM и не требуют действующего API-ключа.

## Проверяемые сценарии

### 1. Успешная проверка текста

**Вход:** непустой текст и допустимый стиль.

**Ожидаемый результат:** запрос передаётся в LLM, а интерфейс возвращает замечания модели.

**Результат:** пройден. Проверяется тестом `test_valid_text_returns_remarks`.

### 2. Текст с исправлениями

**Вход:** непустой текст, допустимый стиль и формат `Текст с исправлениями`.

**Ожидаемый результат:** LLM получает инструкцию переписать исходный текст в выбранном стиле и вернуть только исправленный текст.

**Результат:** пройден. Проверяется тестом `test_corrected_text_format_returns_rewritten_text`.

### 3. Раздельное кеширование форматов

**Вход:** одинаковый текст и стиль, но разные форматы ответа.

**Ожидаемый результат:** для каждого формата создаётся отдельная запись кеша и выполняется отдельный вызов LLM.

**Результат:** пройден. Проверяется тестом `test_response_formats_use_separate_cache_entries`.

### 4. Пустой текст

**Вход:** пустая строка или строка только из пробелов.

**Ожидаемый результат:** возвращается сообщение `Напишите текст для проверки.`, вызов LLM не выполняется.

**Результат:** пройден. Проверяется тестом `test_empty_input_is_rejected_before_api_call`.

### 5. Слишком длинный текст

**Вход:** текст длиной более 10 000 символов.

**Ожидаемый результат:** возвращается сообщение `Слишком длинный текст — сократите или разбейте на части.`, вызов LLM не выполняется.

**Результат:** пройден. Проверяется тестом `test_long_input_is_rejected_before_api_call`.

### 6. Недоступность внешней модели

**Вход:** корректный текст при сетевой ошибке LLM.

**Ожидаемый результат:** пользователь получает безопасное сообщение `Не удалось получить ответ. Попробуйте ещё раз.` без текста исключения и сведений о провайдере.

**Результат:** пройден. Проверяется тестом `test_network_error_is_safe_for_ui`.

### 7. Повторный запрос и TTL-кеш

**Вход:** два одинаковых запроса с одним текстом и стилем.

**Ожидаемый результат:** второй запрос получает результат из кеша, повторный вызов LLM не выполняется.

**Результат:** пройден. Проверяется тестом `test_identical_request_uses_cache`.

### 8. Нулевая настройка повторов

**Вход:** `LLM_MAX_RETRIES=0` и ошибка сетевого вызова.

**Ожидаемый результат:** выполняется минимум одна попытка обращения к LLM, после чего возвращается ошибка сети.

**Результат:** пройден. Проверяется тестом `test_zero_retries_still_performs_one_attempt`.

## Команды проверки

Команды выполняются из каталога `MyLLMService`:

```powershell
python -m unittest discover -s tests -v
python -m compileall -q app tests gradio_app.py
ruff check app tests gradio_app.py
```

## Ручная проверка интерфейса

1. Создать виртуальное окружение и установить зависимости:

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Создать `.env` из `.env.example` и указать `AUTHORIZATION_KEY`.
3. Запустить сервис:

   ```powershell
   python gradio_app.py
   ```

4. Открыть адрес Gradio из консоли.
5. Проверить успешный запрос, пустой ввод, текст длиннее 10 000 символов и недоступность LLM.

Ручной запуск с реальным внешним сервисом LLM зависит от доступности сети и корректности API-ключа; автоматические тесты не используют внешнюю модель.
